# 三关形式化：定义、失效矩阵、可执行检查表（S1b）

> 目的：把"注入有效性 / 测量有效性 / 收敛有效性"从经验清单变成**可判定的性质**。
> 每条性质给出：定义、判定阈值、失败时的证据、以及它对应哪个缺陷族。
> 配套脚本：`scripts/gate_check.py`（一条命令跑三关，输出 PASS/FAIL + 证据）。

---

## 1. 记号

| 符号 | 含义 |
|---|---|
| `C` | 一次实验的配置：`C = (seed, fault, dr, terrain, env)` |
| `N` | 并行环境数 |
| `e` | 环境索引，`e ∈ {1..N}` |
| `q_e(t)` | 环境 e 在 t 步的**物理执行器向量**：`(torque_limits, p_gains, d_gains)` 在故障关节上的取值 |
| `q̄_e` | 标称值（无故障时应有的值） |
| `M` | 注入形态：`free_swing`（力矩=0）/ `degrade(k)`（力矩×k）/ `lock(κ)`（PD×κ + 每步位置钉住） |
| `I_M(·)` | 形态 M 的注入算子：`q̄ → q_M` |
| `Ĉ` | **声称**被注入的环境集合（由 `C.fault` 的概率抽样决定） |
| `Ê` | **实际**被标记为故障的环境集合（`fault_states ≠ 0`） |
| `R` | 报告的指标值（如末 100 迭代平均回报） |

## 2. 三关

### P1｜注入有效性（Injection Validity）

**定义**：一次注入是有效的，当且仅当同时满足

| 子性质 | 形式 | 阈值 |
|---|---|---|
| **P1-a 支持集** | 设 `n` = **本次抽样次数**（reset 事件数，不是环境数 `N_env`）；观测故障数 `k`。**单侧精确二项检验** `P(X ≤ k | n, p) < α` 即判"实际注入率低于声称值" | α = 0.01 |
| **P1-b 效果** | `∀e ∈ Ê, ∀j ∈ 故障关节: q_e,j ≠ q̄_e,j` | 任一相等即失败 |
| **P1-c 无误标** | `∀e ∉ Ê: q_e = q̄_e` | 任一不等即失败 |
| **P1-d 形态保真** | `∀e ∈ Ê: ‖q_e − I_M(q̄_e)‖∞ ≤ ε` | ε = 1e-6 |

> ⚠️ **2026-10-30 修正（原判据写错）**：初版写的是 `|Ê|/n ∈ [p−3σ, p+3σ]`，但**没有定义 n 是什么**。
> 代入同一案例：`n=77` 时判带 `[0, 20.3%]`，观测 `1/77=1.3%` 落带内 ⇒ **PASS**；
> 代入 `n=4096`（环境数）时判带 `[8.6%, 11.4%]` ⇒ **FAIL**。同一份数据两种判定 = 判据不可判定。
> 改为精确二项后：`P(X≤1 | n=77, p=0.1) = 0.00286 < 0.01` ⇒ 稳定判"注入率显著低于声称"，
> 与 n 的取值无关。**记号的单位必须在表里写死**（抽样次数 vs 环境数）。

**为什么是这四条**：P1-a 抓"概率口径"类缺陷（配置 10% 实际 0.13%）；P1-b 抓"标记了但没落地"；P1-c 抓"健康环境被污染"；P1-d 抓"三形态退化成同一种"。

**证据**：逐环境的 `(e, 关节, before, after)` 三元组；失败时打印第一个反例。

### P2｜测量有效性（Measurement Validity）

**定义**：报告的 `R` 是有效的，当且仅当

| 子性质 | 形式 | 阈值 |
|---|---|---|
| **P2-a 口径声明** | `R` 的**定义**被显式声明：`R = φ(D; W, A, R_def)`，其中 `W`=窗口、`A`=聚合（均值/中位数）、`R_def`∈{裁剪回报, 未裁剪回报, 任务回报, RMST} | 未声明即失败 |
| **P2-b 双报** | 若 `R_def = 裁剪回报`，则必须同时报**未裁剪**值及其差值（裁剪质量） | 缺一即失败 |
| **P2-c 窗口敏感** | 至少报 `W ∈ {100, 300, 500}` 三档；若三档极差 > 5pp，必须声明主窗口并解释 | 未报即失败 |
| **P2-d 可加性** | `Σ_terms 回合贡献 = 总回报`（未裁剪口径），`|Σ − 总| / |总| ≤ 1e-3` | 越界即失败 |

**为什么是这四条**：P2-a 抓"没定义";P2-b 抓"裁剪掩盖代价"（我们实测 87.5%）；P2-c 抓"窗口挑出来的效应"（我们实测 −11.3% vs −16.6%）；P2-d 抓"分项与总量不是同一批回合"。

### P3｜收敛有效性（Convergence Validity）

**定义**：在迭代 `T` 处比较两个臂是**可接受的**，当且仅当对每个臂

| 子性质 | 形式 | 阈值 |
|---|---|---|
| **P3-a 平台** | 设 `B_k` 为第 k 个 500 迭代块的均值，则 `|mean(B_last) − mean(B_prev)| < δ` | δ = 0.5（回报单位，约 3%） |
| **P3-b 无单向趋势** | 末三块不得同号单调（`B_{k-2} < B_{k-1} < B_k` 或反之） | 出现即失败 |
| **P3-c 披露** | 必须报告两臂的块序列（至少末 3 块），而不只是终点 | 未报即失败 |

**为什么**：这一关如果不过，比较的是"谁跑得快"而不是"谁更好"——我们在 3000 迭代处实测到 −11.3% 的假效应，续训到 6500 后归零。
